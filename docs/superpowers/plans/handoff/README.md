# Ticket numbers in this folder

The dated files here were written while ThatApp lived on Codeberg, and they keep its numbers: `#<n>` is Codeberg issue or pull request `<n>`, at `https://codeberg.org/DionGerrese/ThatApp/issues/<n>`. The project moved to GitHub on 2026-11-19. Open tickets got new GitHub numbers; the valuable closed ones are in [`docs/archive/codeberg/`](../../../archive/codeberg/README.md).
