under subagent-driven development. The regression-test risk the ticket named — hashed chunks, so
Today's import cannot be held by filename — was solved by reading the router's route table

request. An in-page `import()` of the same URL after release is the barrier that proves the stale
continuation already ran. Chromium's `route.fetch()` cannot reach `that-app` (the host-resolver
mapping is browser-only), so the test re-fetches through `THAT_BASE_URL`, the pattern
`tooltip.spec.ts` already used.

mount an overtaken navigation no longer delivers — fixed and re-reviewed. PR #152.

stale render in a detached container has finished. Cost if wrong: a reviewer asks for one.
