## The overnight merges, and the label the merge left behind

The morning opened against a board that had moved without this machine knowing. `git fetch` was
still failing on SSH auth, so the Codeberg API was the only honest source; once the owner merged the
handoff pull request, the fetch went through and the two agreed.

What had happened while the session was down:

- **PR #90 merged**, closing **#11**. The week view — the rollup grid, per-cell push state and the
  rail that follows the mounted view — is on `main`.
- **PR #93 merged**, the 2026-09-02 handoff.
- The **intake queue was triaged to one**. Thirteen tickets went to `status/needs-refinement` and
  **#59** was declined with `wontfix`. Only **#74** is left at intake.
- **#89** and **#91**, raised late on 2026-09-02, were both approved to `status/needs-refinement`.

**One hygiene defect, fixed by hand.** #11 closed carrying `status/in-progress`: the forge closes an
issue through `Closes #<n>` but does not touch its labels. Removed, and the rule promoted into
`handoff.md` — check the status label after every merge, because the merge will not do it.

**The branch ledger was re-verified, and `git branch --merged` was found to under-report it.** The
repository merges by rebase, so a merged branch is not an ancestor of `main` and that command misses
it. Four branches were being carried as unmerged for that reason alone. `git cherry codeberg/main
<branch>` is the check that tells the truth; seventeen local branches are droppable and only
`worktrees-without-the-tax` is genuinely unmerged.

**State at the start of the working day:** nothing in progress, no open pull requests, 27 open
issues — #8 and #10 ready, 24 in refinement, #74 at intake.

## The afternoon: a visual identity, and two views redesigned around it

The owner asked for a redesign of the UI, framed as an **opposite identity** to a reference brand —
an evil twin in *manners, not function*. The whole afternoon ran in the **superpowers browser
companion**, thirteen screens, each decision chosen against alternatives that were built and compared
rather than described.

**A correction worth carrying:** the session opened by publishing a Claude Design canvas, which the
owner stopped and deleted. Design work here is **local**, on the companion, never a cloud artifact.
Yesterday had already set that precedent and it was not read.

### What was settled

Dark by default with light a full peer · the rail separating **by value alone** · the reference's
five-step radius ruler inherited and stood on at its **bottom** end · **Chivo** for words and **Chivo
Mono** for figures · the small end of the type ramp up one pixel, which retires `--text-md` · icons
drawn rather than typed · tooltips in the top layer · a `3xl` breakpoint capping the content column.

Then Today and Week rebuilt as tables, two-up instance cards from `xl`, a pin control per row, a
global search that is a lookup rather than a filter, every Week cell a control, and the entries
dialog restructured. Settings went to #89 for a full redesign: a cog beside the wordmark opening a
modal dialog that scrolls as one piece.

### What it cost, and why

Four rounds of "that is misaligned" were all **cascade collisions**, not layout mistakes:

- the mocks used the class name `card`, which the companion's own frame styles with a border, a
  pointer cursor and a hover lift;
- a button reset used `all: unset`, which outranks every component rule after it — icon buttons lost
  their size, Push lost its colour;
- two copies of a stylesheet disagreed, and the stale one kept supplying every property the newer one
  did not restate;
- `[hidden]` is a user-agent rule, so an author `display:` beats it and hidden things showed.

Each looked like a design error and none was. All four are recorded in
`2026-09-03-today-and-week-design.md`.

### Read the source, not the memory

Reading the shipped code turned up things no amount of drawing would have: Inter has **no**
monospaced companion, so the Inter route was dead on its own terms before the brief killed it;
`that-ticket-row`'s docstring argues *against* the mono key on a budget it misidentifies;
`that-alert` tells warning and failed apart **by colour alone**; and eight typed characters across
four files are doing an icon's job.

### Left for tomorrow

shown last and only briefly; the wash is `color-mix(in oklab, var(--ink) 11%, transparent)`, which
was tuned against the dark ground and has not been judged on paper-white. The rail keeps its own
`--hover-rail` and is not part of the question.
