**Goal:** A path `{id}` that is not a positive integer names no resource, so every `{id}` route
answers it exactly as it answers a well-formed id that does not exist: 404 `not_found`.

**Architecture:** One helper, `idFromPath`, next to `writeError` in `internal/server/json.go`,
parses the wildcard and writes the 404 itself with the route's message. The three per-resource
helpers (`instanceIDFromPath`, `pinIDFromPath`, `entryIDFromPath`) are deleted. The missing-row
answers for pins and entries change code from `pin_not_found` / `entry_not_found` to `not_found`,
because the issue's second criterion requires malformed and missing to share status *and* code.

**Tech Stack:** Go (`internal/server`), the design of record, one Playwright stub.

**Spec:** Codeberg issue #55 (the decision and acceptance criteria), and
`docs/superpowers/specs/2026-08-04-thatapp-design.md` § *API surface*.

## Global Constraints

- Docker only: run Go through `docker compose run --rm --no-deps app …` or `make`, never bare.
- Messages per route, verbatim: `no such instance`, `no such pin`, `no such entry`.
- Code on every `{id}` 404: `not_found`.
- Request *body* validation stays 400 `invalid_request` — out of scope.
- The `{id}` routes and methods: `PATCH /api/instances/{id}`, `DELETE /api/instances/{id}`,
  `POST /api/instances/{id}/test`, `DELETE /api/pins/{id}`, `PATCH /api/entries/{id}`,
  `DELETE /api/entries/{id}`.

```go
package server

import (
	"encoding/json"
	"net/http"
	"testing"
	"time"
)

// TestEveryIDRouteAnswersAMalformedIDAsAMissingOne: a path segment that is not
// a positive integer names no resource, so it gets the same 404 not_found a
// well-formed id with no row behind it gets, on every {id} route and method.
func TestEveryIDRouteAnswersAMalformedIDAsAMissingOne(t *testing.T) {
	routes := []struct {
		method, prefix, suffix, body, message string
	}{
		{http.MethodPatch, "/api/instances/", "",
			`{"name":"X","siteUrl":"https://x.atlassian.net","email":"me@example.com"}`, "no such instance"},
		{http.MethodDelete, "/api/instances/", "", "", "no such instance"},
		{http.MethodPost, "/api/instances/", "/test", "", "no such instance"},
		{http.MethodDelete, "/api/pins/", "", "", "no such pin"},
		{http.MethodPatch, "/api/entries/", "", `{"seconds":900}`, "no such entry"},
		{http.MethodDelete, "/api/entries/", "", "", "no such entry"},
	}
	ids := []struct{ name, id string }{
		{"non-numeric", "abc"},
		{"zero", "0"},
		{"negative", "-1"},
		{"beyond int64", "9223372036854775808"},
		{"well-formed but missing", "999999"},
	}

	for _, route := range routes {
		for _, id := range ids {
			t.Run(route.method+" "+route.prefix+"{id}"+route.suffix+" "+id.name, func(t *testing.T) {
				srv, _, _ := serverInZone(t, "Europe/Amsterdam",
					time.Date(2026, 8, 21, 12, 5, 0, 0, time.UTC))

				rec := callEntries(t, srv, route.method, route.prefix+id.id+route.suffix, route.body)

				assertRejected(t, rec, http.StatusNotFound, "not_found")
				var body errorBody
				if err := json.Unmarshal(rec.Body.Bytes(), &body); err != nil {
					t.Fatalf("decoding %s: %v", rec.Body.String(), err)
				}
				if body.Message != route.message {
					t.Errorf("message = %q, want %q", body.Message, route.message)
				}
			})
		}
	}
}
```

- [ ] **Step 3: Add `idFromPath` to `internal/server/json.go`** (below `writeError`; add `strconv` to imports):

```go
// idFromPath reads the {id} wildcard. Anything but a positive integer names no
// resource, so it is answered exactly as a missing row is: 404 not_found.
func idFromPath(w http.ResponseWriter, r *http.Request, message string) (int64, bool) {
	id, err := strconv.ParseInt(r.PathValue("id"), 10, 64)
	if err != nil || id <= 0 {
		writeError(w, http.StatusNotFound, "not_found", message)
		return 0, false
	}

	return id, true
}
```
