# Store Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `internal/store` — the SQLite persistence layer, its migration mechanism, and instance CRUD — so later tickets have somewhere to write.

**Architecture:** One concrete `Store` type wrapping `*sql.DB`. Connection pragmas are set in the DSN so they reach every pooled connection. Migrations are timestamp-named SQL files embedded with `go:embed`, applied in lexicographic order, each inside a transaction that also records it in a `schema_migrations` table.

**Tech Stack:** Go 1.26, `database/sql`, `modernc.org/sqlite` v1.56.0 (pure Go, keeps `CGO_ENABLED=0`).

This plan implements **GitHub issue #2**. The design it follows is
`docs/superpowers/specs/2026-08-07-store-design.md`; the schema it builds is fixed by
`docs/superpowers/specs/2026-08-04-work-dashboard-design.md`.

## Global Constraints

Every task's requirements implicitly include all of these.

- **Everything runs in Docker.** There is no Go on the host — never run `go` bare, even though the host happens to have it installed. Use `docker compose run --rm --no-deps app go ...` or a `make` target.
- Go module path: `github.com/dgerrese/work-dashboard`. Go 1.26.
- **The only new dependency permitted is `modernc.org/sqlite`.** The approved set is that plus `golang.org/x/sync`. Anything else needs a reason the stdlib cannot meet.
- The build must stay `CGO_ENABLED=0` so the production image can remain `scratch`.
- Errors wrap with `%w` and say what was attempted.
- Table-driven tests with `t.Run` subtests. No test touches a real network.
- `make verify` is the merge gate and must pass before any task is done.

## Verified environment facts

These were confirmed empirically against `modernc.org/sqlite` v1.56.0 in the project's container before this plan was written. Do not re-derive them; do not "correct" them from memory.

- The registered driver name is **`sqlite`**, not `sqlite3`.
- DSN pragmas use the form `?_pragma=name(value)`, repeated per pragma, and they do apply to pooled connections.
- A single `Exec` accepts **multiple `;`-separated statements**, so a whole migration file can be executed in one call.
- SQLite DDL **is transactional**: `CREATE TABLE` inside a transaction disappears on rollback, and a syntax error mid-file rolls back the statements before it.

`internal/store/store.go`:

```go
// Package store persists the dashboard's state in SQLite.
package store

import (
	"database/sql"
	"fmt"

	_ "modernc.org/sqlite" // registers the "sqlite" driver
)

// Store owns the database handle. Open is its sole constructor.
type Store struct {
	db *sql.DB
}

// Open connects to the SQLite database at path.
//
// The pragmas travel in the DSN rather than as separate statements so that they
// apply to every connection database/sql pools, not only to whichever one
// happened to execute them. foreign_keys matters most: SQLite defaults it off,
// and without it the schema's ON DELETE CASCADE clauses silently do nothing.
func Open(path string) (*Store, error) {
	dsn := fmt.Sprintf(
		"file:%s?_pragma=foreign_keys(1)&_pragma=journal_mode(WAL)&_pragma=busy_timeout(5000)",
		path,
	)

	db, err := sql.Open("sqlite", dsn)
	if err != nil {
		return nil, fmt.Errorf("opening database %s: %w", path, err)
	}

	// sql.Open is lazy, so a bad path only surfaces on first use. Ping now, to
	// fail at startup rather than on the first request.
	if err := db.Ping(); err != nil {
		_ = db.Close()
		return nil, fmt.Errorf("connecting to database %s: %w", path, err)
	}

	return &Store{db: db}, nil
}

// Close releases the database handle.
func (s *Store) Close() error {
	return s.db.Close()
}
```

```go
func TestMigrateIsIdempotent(t *testing.T) {
	path := filepath.Join(t.TempDir(), "test.db")

	first, err := Open(path)
	if err != nil {
		t.Fatalf("first Open() returned error: %v", err)
	}
	if err := first.Close(); err != nil {
		t.Fatalf("closing first store: %v", err)
	}

	second, err := Open(path)
	if err != nil {
		t.Fatalf("second Open() returned error: %v", err)
	}
	t.Cleanup(func() { _ = second.Close() })

	// One row per migration file, not two. A second Open must record nothing new.
	var rows int
	if err := second.db.QueryRow(`SELECT count(*) FROM schema_migrations`).Scan(&rows); err != nil {
		t.Fatalf("counting schema_migrations: %v", err)
	}

	names, err := migrationNames()
	if err != nil {
		t.Fatalf("migrationNames() returned error: %v", err)
	}
	if rows != len(names) {
		t.Errorf("schema_migrations has %d rows, want %d (one per migration file)", rows, len(names))
	}
}

func TestFailedMigrationLeavesNothingBehind(t *testing.T) {
	s := openTestStore(t)

	// A migration whose second statement is invalid. The first must not survive:
	// SQLite DDL is transactional, which is what makes a failed migration safe.
	const bad = `
CREATE TABLE should_not_survive (id INTEGER PRIMARY KEY);
CREATE TABLE this is not valid sql;
`
	if err := s.applyMigration("9999-01-01_000000_bad.sql", []byte(bad)); err == nil {
		t.Fatal("applyMigration() succeeded on invalid SQL, want error")
	}

	if tableExists(t, s, "should_not_survive") {
		t.Error("the failed migration's first statement persisted; the transaction did not roll back")
	}

	var n int
	if err := s.db.QueryRow(
		`SELECT count(*) FROM schema_migrations WHERE version = ?`, "9999-01-01_000000_bad.sql",
	).Scan(&n); err != nil {
		t.Fatalf("counting schema_migrations: %v", err)
	}
	if n != 0 {
		t.Errorf("failed migration recorded %d rows in schema_migrations, want 0", n)
	}
}
```

`internal/store/migrate.go`. Note `applyMigration` takes the body as an argument rather than
reading it itself — that is what lets the rollback test feed it deliberately broken SQL without
adding a file to the embedded set:

```go
package store

import (
	"embed"
	"fmt"
	"io/fs"
	"slices"
	"time"
)

//go:embed migrations/*.sql
var migrationsFS embed.FS

// migrate applies every embedded migration this database has not recorded yet,
// in lexicographic filename order.
//
// Each migration and the row recording it commit together. A migration applied
// without its row would run again on the next boot; a row without its migration
// would skip it forever.
func (s *Store) migrate() error {
	if _, err := s.db.Exec(`
		CREATE TABLE IF NOT EXISTS schema_migrations (
			version    TEXT PRIMARY KEY,
			applied_at TEXT NOT NULL
		)`); err != nil {
		return fmt.Errorf("creating schema_migrations: %w", err)
	}

	applied, err := s.appliedMigrations()
	if err != nil {
		return err
	}

	names, err := migrationNames()
	if err != nil {
		return err
	}

	for _, name := range names {
		if applied[name] {
			continue
		}

		body, err := migrationsFS.ReadFile("migrations/" + name)
		if err != nil {
			return fmt.Errorf("reading migration %s: %w", name, err)
		}
		if err := s.applyMigration(name, body); err != nil {
			return fmt.Errorf("applying migration %s: %w", name, err)
		}
	}

	return nil
}

// appliedMigrations returns the set of migration filenames already recorded.
func (s *Store) appliedMigrations() (map[string]bool, error) {
	rows, err := s.db.Query(`SELECT version FROM schema_migrations`)
	if err != nil {
		return nil, fmt.Errorf("reading schema_migrations: %w", err)
	}
	defer func() { _ = rows.Close() }()

	applied := make(map[string]bool)
	for rows.Next() {
		var version string
		if err := rows.Scan(&version); err != nil {
			return nil, fmt.Errorf("scanning schema_migrations: %w", err)
		}
		applied[version] = true
	}
	if err := rows.Err(); err != nil {
		return nil, fmt.Errorf("iterating schema_migrations: %w", err)
	}

	return applied, nil
}

// migrationNames lists the embedded migration filenames in the order they must
// be applied. The timestamp naming scheme sorts correctly under plain string
// comparison, including when a collision added a millisecond suffix.
func migrationNames() ([]string, error) {
	entries, err := fs.ReadDir(migrationsFS, "migrations")
	if err != nil {
		return nil, fmt.Errorf("reading embedded migrations: %w", err)
	}

	names := make([]string, 0, len(entries))
	for _, entry := range entries {
		names = append(names, entry.Name())
	}
	slices.Sort(names)

	return names, nil
}

// applyMigration runs body and records name, in one transaction.
func (s *Store) applyMigration(name string, body []byte) error {
	tx, err := s.db.Begin()
	if err != nil {
		return fmt.Errorf("beginning transaction: %w", err)
	}
	defer func() { _ = tx.Rollback() }()

	if _, err := tx.Exec(string(body)); err != nil {
		return fmt.Errorf("executing: %w", err)
	}

	if _, err := tx.Exec(
		`INSERT INTO schema_migrations (version, applied_at) VALUES (?, ?)`,
		name, time.Now().UTC().Format(time.RFC3339),
	); err != nil {
		return fmt.Errorf("recording: %w", err)
	}

	return tx.Commit()
}
```

  - `func (s *Store) Instances(ctx context.Context) ([]Instance, error)`
  - `func (s *Store) Instance(ctx context.Context, id int64) (*Instance, error)`
  - `func (s *Store) UpdateInstance(ctx context.Context, id int64, name, baseURL, email string, tokenEnc []byte) error`
  - `func (s *Store) DeleteInstance(ctx context.Context, id int64) error`

**A trap to avoid.** `created_at` is stored as RFC3339, which has one-second resolution, while
`time.Now()` carries nanoseconds. If the timestamp is not truncated before storing, the value read
back is *earlier* than the `time.Now()` captured just before the call, and the natural
"created_at falls between before and after" assertion fails intermittently. `CreateInstance`
therefore truncates to the second, and returns the truncated value it stored.

```go
package store

import (
	"context"
	"database/sql"
	"fmt"
	"time"
)

// Instance is a configured Jira Cloud site.
//
// TokenEnc is opaque to the store: it is written and read unchanged, and
// encrypting it is the caller's job.
type Instance struct {
	ID        int64
	Name      string
	BaseURL   string
	Email     string
	TokenEnc  []byte
	CreatedAt time.Time
}

// instanceColumns is the select list every instance query shares, in the order
// scanInstance expects.
const instanceColumns = `id, name, base_url, email, api_token_enc, created_at`

// scanner is satisfied by both *sql.Row and *sql.Rows.
type scanner interface {
	Scan(dest ...any) error
}

func scanInstance(row scanner) (*Instance, error) {
	var (
		inst      Instance
		createdAt string
	)
	if err := row.Scan(
		&inst.ID, &inst.Name, &inst.BaseURL, &inst.Email, &inst.TokenEnc, &createdAt,
	); err != nil {
		return nil, err
	}

	parsed, err := time.Parse(time.RFC3339, createdAt)
	if err != nil {
		return nil, fmt.Errorf("parsing created_at %q: %w", createdAt, err)
	}
	inst.CreatedAt = parsed

	return &inst, nil
}

// CreateInstance stores a new Jira site and returns it with its assigned id.
func (s *Store) CreateInstance(
	ctx context.Context, name, baseURL, email string, tokenEnc []byte,
) (*Instance, error) {
	// Truncated because created_at is stored as RFC3339, which has one-second
	// resolution. Without this the returned value would not equal the stored one.
	createdAt := time.Now().UTC().Truncate(time.Second)

	result, err := s.db.ExecContext(ctx,
		`INSERT INTO instances (name, base_url, email, api_token_enc, created_at)
		 VALUES (?, ?, ?, ?, ?)`,
		name, baseURL, email, tokenEnc, createdAt.Format(time.RFC3339),
	)
	if err != nil {
		return nil, fmt.Errorf("inserting instance %q: %w", name, err)
	}

	id, err := result.LastInsertId()
	if err != nil {
		return nil, fmt.Errorf("reading id of new instance %q: %w", name, err)
	}

	return &Instance{
		ID: id, Name: name, BaseURL: baseURL, Email: email,
		TokenEnc: tokenEnc, CreatedAt: createdAt,
	}, nil
}

// Instances returns every stored Jira site, oldest first.
func (s *Store) Instances(ctx context.Context) ([]Instance, error) {
	rows, err := s.db.QueryContext(ctx,
		`SELECT `+instanceColumns+` FROM instances ORDER BY id`)
	if err != nil {
		return nil, fmt.Errorf("querying instances: %w", err)
	}
	defer func() { _ = rows.Close() }()

	instances := []Instance{}
	for rows.Next() {
		inst, err := scanInstance(rows)
		if err != nil {
			return nil, fmt.Errorf("scanning instance: %w", err)
		}
		instances = append(instances, *inst)
	}
	if err := rows.Err(); err != nil {
		return nil, fmt.Errorf("iterating instances: %w", err)
	}

	return instances, nil
}

// Instance returns one stored Jira site. A missing id yields an error wrapping
// sql.ErrNoRows.
func (s *Store) Instance(ctx context.Context, id int64) (*Instance, error) {
	row := s.db.QueryRowContext(ctx,
		`SELECT `+instanceColumns+` FROM instances WHERE id = ?`, id)

	inst, err := scanInstance(row)
	if err != nil {
		return nil, fmt.Errorf("reading instance %d: %w", id, err)
	}

	return inst, nil
}

// UpdateInstance overwrites a stored Jira site. A missing id yields an error
// wrapping sql.ErrNoRows.
func (s *Store) UpdateInstance(
	ctx context.Context, id int64, name, baseURL, email string, tokenEnc []byte,
) error {
	result, err := s.db.ExecContext(ctx,
		`UPDATE instances SET name = ?, base_url = ?, email = ?, api_token_enc = ? WHERE id = ?`,
		name, baseURL, email, tokenEnc, id,
	)
	if err != nil {
		return fmt.Errorf("updating instance %d: %w", id, err)
	}

	return errNoRowsIfUnaffected(result, "updating instance", id)
}

// DeleteInstance removes a stored Jira site, cascading to its pinned issues,
// time entries and timer. A missing id yields an error wrapping sql.ErrNoRows.
func (s *Store) DeleteInstance(ctx context.Context, id int64) error {
	result, err := s.db.ExecContext(ctx, `DELETE FROM instances WHERE id = ?`, id)
	if err != nil {
		return fmt.Errorf("deleting instance %d: %w", id, err)
	}

	return errNoRowsIfUnaffected(result, "deleting instance", id)
}

// errNoRowsIfUnaffected turns "matched nothing" into sql.ErrNoRows. UPDATE and
// DELETE against a missing id are not driver errors, so without this they would
// succeed silently.
func errNoRowsIfUnaffected(result sql.Result, action string, id int64) error {
	affected, err := result.RowsAffected()
	if err != nil {
		return fmt.Errorf("%s %d: reading rows affected: %w", action, id, err)
	}
	if affected == 0 {
		return fmt.Errorf("%s %d: %w", action, id, sql.ErrNoRows)
	}

	return nil
}
```
