# Retro — 2026-10-05

**Date:** 2026-10-05
**Supersedes:** nothing — the project's first retro
**Superseded by:** nothing

**Window:** everything, from 2026-08-12 to 2026-10-05. Sources: every file in
`docs/superpowers/plans/handoff/`, `handoff.md`, and the Codeberg record of every closed pull
request and issue. Counts were re-checked against the Codeberg API on the day.

## Findings

Each finding cleared the bar: it recurred in two or more tickets, or one occurrence reached review or
`main`. The first eight became proposals; the rest are recorded for the next retro.

1. **Closed tickets keep `status/in-progress`.** About sixty closes since 2026-08-28, #123 on the
   morning of this retro among them. *Gate:* none — the merge is the owner's and the strip was the
   session's, with nothing connecting them. eod's label check made it worse: `tea issues list`
   returns 30 issues (verified: 34 open and 135 closed exist), and eod said "report, never fix" while
   `ticket-workflow` said strip, so on 2026-09-22 #8 and #186 were stripped and #139 and #83 left.
   `ticket-workflow` also said a done ticket "keeps the label". → **Proposal 1**, and intake **#276**
   for the structural fix (a workflow on `issues: closed`).
2. **A defect in the ticket's own feature was filed beside it, and the ticket shipped.** #121 against
   #10 (filed 14:33, PR #120 merged 16:31 on 2026-09-08 — verified), #207–#209 against #185 (PR #210),
   #236 and #231 against #143 (PR #229), #221 against #127 (PR #223). *Gate:* the whole-branch review
   found each one; the intake rule ("a bug noticed in passing") then sent it away. → **Proposal 2**
3. **A rule the owner set never reached its skill.** 2026-09-21's in-progress-first rule sat in a day
   file and the 2026-09-30 run walked past #123; two rules on 2026-09-09 and the vault rule on
   2026-09-16 lived only in machine memory. *Gate:* eod verifies claims about PRs, branches and
   commits, not rules. → **Proposal 3**
4. **Tests that could not fail.** #5, #7, #12, #9, #99, #95, #117, #121, #84, #8, #227, #209, #236.
   #99 and #117's three reached `main`. *Gate:* RED-before-GREEN proves a test failed once, not why.
   → **Proposal 4**
5. **A status move over the owner's comment.** #207 and #208 to `status/todo` on 2026-09-29 against
   a comment that they wait for #123. *Gate:* refinement named code and design, not comments.
   → **Proposal 5**
6. **The session moved the working tree under a running subagent.** Three times on 2026-09-21; one
   corrupted #134's 20-run measurement with eleven false Firefox failures. Also 2026-09-06. *Gate:*
   none — branch-in-place shares one directory. → **Proposal 6**
7. **Duplicate issues from a retried create.** #232, #248, #254. *Gate:* a handoff fact, not a rule;
   #248 came three days after it was written. → **Proposal 7**
8. **Design mocks collided with the companion frame's CSS.** `.card` on 2026-09-03 (four rounds of
   false "misaligned") and on 2026-09-30 (#246, every tooltip clipped). → **Proposal 8**
9. **The design sources contradicted each other, and every gate read the wrong one.** 2026-09-22's
   green running key passed the design session, four task reviews, the whole-branch review and both
   suites; one screenshot caught it. Earlier: 2026-09-02, 2026-09-09 (R13 cog), 2026-09-10 (week
   doc), #184. *No proposal:* nothing checks design documents against each other, and no mechanism
   short of that was found. The screenshot rule is what worked.
10. **Correct changes collided semantically, across tickets.** #84's JQL (2026-09-10, a Critical);
    #8 meeting #83 (#183, #192); #185 against #192's tests; #251 against #200's guard. The
    pre-flight conflict scan reasons about files and is defined nowhere in the rules. *No proposal:*
    no rule found that would see a collision with no shared file.
11. **A sibling pull request turned `main` red.** #210 merged beside #214's prettier gate on
    2026-09-24; `main` failed lint until PR #224, and the handoff wrongly said both gates were green.
    *No proposal:* re-gating every open PR after each merge is the owner's merge-time cost to choose;
    a forge setting requiring up-to-date branches is the likely fix.
12. **CI's ten-minute cap hit twice** (#186, #239), both fixed by tickets. Nothing watches job
    duration; a cancelled job reports `failure` with no output.
13. **eod left the handoff unpushed two days running** (2026-09-28, 2026-09-29), after the eod rule
    that forbids it. The 2026-09-28 cause was a shell check with no permission verdict.
14. **Plans with defects reached execution** — #6, #51, #87, #11, #95, #84. Nothing reviews a plan
    before it runs.
15. **Review findings were applied without measuring them** — 2026-09-02, and 2026-09-06 where a
    review's claim that `hidePopover()` throws was followed and was false.
16. **A flake sat for seven weeks behind `retries: 1`** (#134).

**Already fixed, and not recurring since the rule:** work existing only on one machine (#7, the eod
skill); stale `handoff.md` claims (eod's verify step); defects only visible in light theme (paired
screenshots); the wrong dev-stack port (`THAT_PORT` in `CLAUDE.md`).

**Checked and clean:** every pull request after 2026-09-18 has a title prefix; every ticket PR but
#224 says `Closes #<n>`; no closed issue carried a `status/*` label after #123 was stripped.
